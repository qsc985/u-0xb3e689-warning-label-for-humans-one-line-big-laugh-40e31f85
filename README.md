Entry for the [make.fun bounty](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

`main.py` writes the label to `/output/entry.txt`:

> WARNING: This human ships with no instructions, no off switch, and will press every button marked DO NOT PRESS.

Run it with:

```sh
python3 main.py
```
